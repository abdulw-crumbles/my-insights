Methodology & notes
  • Before = pre-revision targets (last Postgres load). After = values now live in the sheet; H1 identical, H2 revised. Quarter totals reconcile exactly to the consolidated AOP (C/D).
  • Avg SQL deal size = Pipeline ÷ SQL. Marketing deal size rises in H2 because SQL falls faster than pipeline; Reseller deal size rises because pipeline scales up while SQL is held.
  • Small ±1–2 unit differences are rounding from even monthly splits and are immaterial.
  • Revenue and mapping keys unchanged. Figures update on the dashboard after the Airflow reload.
